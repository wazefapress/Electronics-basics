# ⚡ تطبيق أساسيات الإلكترونيات (Electronics Basics PWA)

تطبيق ويب تقدمي (PWA) باللغة العربية، مصمم لتقديم محتوى تعليمي شامل ومبسط حول المفاهيم والمكونات الأساسية للدوائر الإلكترونية (مثل الذرة، قانون أوم، الترانزستورات، والبوابات المنطقية). 

## ✨ الميزات الأساسية (Features)

- **📱 تصميم متجاوب بالكامل (Responsive):** واجهة مستخدم تتكيف مع كافة أحجام الشاشات (هواتف، أجهزة لوحية، شاشات حاسوب) بفضل `Bootstrap 5`.
- **📥 قابل للتثبيت (Installable):** يدعم التثبيت المباشر على الأجهزة الذكية كـ Native App بفضل إعدادات `manifest.json`.
- **📶 دعم العمل دون اتصال (Offline Mode):** يتم تخزين جميع الصفحات (HTML) والموارد محلياً باستخدام `Service Worker` و `Cache API`، مما يسمح بتصفح الفصول الدراسية حتى عند انقطاع الإنترنت.
- **🔗 مشاركة سريعة (Web Share API):** زر مشاركة مدمج يتفاعل مع نظام التشغيل لمشاركة التطبيق بسهولة.
- **🎨 واجهة جذابة (UI/UX):** استخدام رموز بصرية دالة لكل فصل عبر `FontAwesome` وتأثيرات حركية تفاعلية.
